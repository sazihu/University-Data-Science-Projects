# Academic and Technical Projects

## 📊 Global GDP and Trend Analysis Project

This project analyzes development indicators using Python, Pandas, and Matplotlib.

### Technologies used:
* Python 3
* Pandas (Data Manipulation)
* Matplotlib (Data Visualization)

### Key Features:
* Data cleaning and string manipulation (cleaning up column headers).
* Time-series plotting of position and economic growth factors.
